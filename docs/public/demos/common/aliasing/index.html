采样与混叠仿真台

相机按帧率对运动采样、麦克风按采样率对声波采样——背后是同一个 Nyquist 定理。切换两种模式，看同一个公式的两张脸。

falias = | f − round(f / fs) · fs |　　采样只忠实保留 f < fs/2 的成分

轮子模式：视觉转速 = 转速 − round(转速/帧率)·帧率；超过 Nyquist（帧率/2）后正转变倒转。声波模式：打开抗混叠滤波后，高于 Nyquist 的成分在采样前被压低——假波消失，但那部分信息也没了。
