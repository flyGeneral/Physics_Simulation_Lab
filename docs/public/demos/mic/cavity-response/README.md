# 异形音腔与高频跌落仿真台（仿真式）

用 Kelly–Lochbaum 分段均匀平面波声管模型（每段 1 mm）演示音腔形状对 mic 频响的影响：
每处截面突变按 r=(A₁−A₂)/(A₁+A₂) 反射声波——单处突变带来平坦的阻抗变换电平差与驻波凹陷；**多级台阶级联则形成宽带高频深跌**（宽阻带）；「渐变锥管」是对照组，同样的容积扩张、平滑过渡几乎没有频率选择性损失。绝对曲线上还可见 Helmholtz 滚降与 λ/2 驻波凹陷。上半部分把压力脉冲慢放 ~×136，可直观看到波在突变处分裂为反射波与透射波。相对曲线按低频归一，只显示频率选择性损失。
