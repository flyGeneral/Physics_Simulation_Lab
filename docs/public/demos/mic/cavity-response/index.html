异形音腔与高频跌落仿真台

声孔 → 音腔 → MEMS 膜片是一条声学传输线。每处截面突变都按反射系数 r=(A₁−A₂)/(A₁+A₂) 反射声波；单处突变主要带来平坦的电平偏移与驻波凹陷，而级联多级突变（台阶）会形成宽带的高频深跌。上半部分把压力脉冲慢放 ~×136，可亲眼看见波在突变处「裂开」。相对曲线已按低频归一，只显示频率选择性损失。

模型：Kelly–Lochbaum 分段均匀平面波声管（每段 1 mm），截面突变处反射精确成立；孔口反射 −0.35、膜片（容性负载）+0.75、每段跨接损耗 0.9994。弯折按「截面突变 + 等效修正」近似；未含粘热损耗与高阶模，绝对幅度仅供定性。「渐变锥管」是对照组：同样的容积扩张，平滑过渡几乎不反射高频。
