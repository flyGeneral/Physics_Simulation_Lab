曲率驱动出自刘慈欣《三体Ⅲ·死神永生》。二维示意：把空间简化为网格，光速 = 光在网格上的传播速度。引擎将身后空间的光速"永久调低"，飞船被前后光速差推动。满功率点火可把尾迹光速压到约一成（演示值，且会缓慢回升扩散），而"黑域"需约 0.006%c（第三宇宙速度以下）——还要再低一个数量级。

常规空间

空间各处光速相同（c₀ ≈ 30万km/s），光子匀速直线飞行。飞船靠核聚变"扔质量"推进，速度有上限——《三体》中恒星级战舰也只有光速的百分之几。点击「点火」启动曲率引擎，或点击画面为飞船设定航向。
