# 傅里叶变换 · 时域与频域的桥

> 关键词：傅里叶级数、正弦基、相关（内积）、吉布斯现象、频谱泄漏

## 原理：一个信号，两套坐标系

时域和频域不是两种信号，而是**同一个信号的两套坐标**：以时间为轴看它的起伏，或以频率为轴看它的成分。傅里叶变换就是两套坐标系之间的换算桥，核心只有两句话：

**合成（级数）**：足够多的正弦波叠加可以搭出任何波形——方波 = 奇次谐波 1/1 + 1/3 + 1/5… 的叠加，锯齿波 = 全部谐波按 1/n 叠加，三角波按 1/n² 收敛得更快。**波形越「尖」，高次谐波衰减越慢**——这是「方波频谱宽」的数学根源。

**拆解（变换）**：想知道信号里有多少频率 k 的成分？拿该频率的正弦基波当**探针**，与信号逐点相乘再求和（内积/相关）：

```text
X(k) = Σₙ x(n) · e^(−i2πkn/N)   → 直觉版：Σ x(n)·sin(2πkn/N)
```

对上了就同号积累出大值，对不上就正负抵消归零。把每个 k 都问一遍，得到的序列就是频谱——**离散傅里叶变换（DFT）的全部**，FFT 只是它的快速算法。

### 两个必然现象

- **吉布斯现象**：谐波数 N 再大，方波跳变处的过冲也只收敛到约 8.95%，不会消失——傅里叶级数在间断点的固有天性；
- **频谱泄漏**：变换默认信号在窗内恰好整数个周期。若不是（真实信号几乎总是不是），能量就摊给邻近频率，谱线长出「裙边」——加窗、补零、窗型选择都是为了对付它。这也是「窗长决定频率分辨率」的直观来源。

### 不确定性

时间上越集中（窄脉冲），频率上越铺开（宽频谱）；反之亦然，Δt·Δf ≥ 常数。它同时解释了：为什么短窗看瞬态、长窗看低频细节，为什么鼓的「咚」没有确定音高，而音叉拖长音才纯净。

## 现象速查

| 图谱/现象 | 傅里叶解释 |
| --- | --- |
| 方波谱线只在奇次谐波 | 波形的半波对称性使偶次系数为零 |
| 尖锐边沿 → 宽频谱 | 1/n 衰减慢，高次谐波显著 |
| 窄脉冲 → 平坦频谱 | 时间集中的极限（δ 函数）频谱恒定 |
| 非整数周期落窗 → 裙边 | 泄漏：截断 = 与矩形窗卷积 |
| 谐波间距 = 基频 | 周期信号的级数只落在整数倍频率上 |

试这些操作：

1. 合成模式：选**方波**，点「▶ 逐项搭建」→ 谐波一根根加进来，方波从圆滑变尖锐；注意过冲始终在 9% 附近徘徊（吉布斯）；
2. 切**三角波**对比 → 谱线按 1/n² 迅速变矮，几项就收敛（边沿「尖度」决定频谱宽度）；
3. 切拆解模式（默认双音）→ 拖**探测频率 k**，看中栏基波与信号对齐/错开，下栏乘积面积（绿正红负）在 k=5 与 k=14 处大幅积累——谱线就是这样「问」出来的；
4. 点「🔄 扫描全频段」→ 探针扫过每个 k，谱线逐根点亮，扫到成分频率时骤然升高；
5. 切「**拍频·泄漏**」预设 → 11.5 周期不是整数，能量摊给邻近 k，谱线长出裙边——真实信号频谱永远有裙边的原因。
