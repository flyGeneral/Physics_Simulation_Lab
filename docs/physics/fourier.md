# 傅里叶变换 · 正弦基上的分解与合成

> 关键词：正交基、内积投影、级数、正交性、吉布斯现象

## 原理一：正弦族是一组「坐标轴」

三维空间里，任何向量都能写成 x̂、ŷ、ẑ 三个**正交基**的线性组合，系数就是坐标。傅里叶的核心思想只有这一句话的推广：

> **正弦族 sin(t), sin(2t), sin(3t), … 是一组无穷多个、两两正交的基——任何（满足宽松条件的）信号都能写成它们的加权和。**

「正交」在信号里的含义和几何里一样：**互相「看不见」**。不同频率的正弦相乘后求和恒为零：

```text
Σₙ sin(2πkn/N) · sin(2πmn/N) = 0   （k ≠ m，正交性）
Σₙ sin(2πkn/N) · sin(2πkn/N) = N/2 （k = m，同频才积累）
```

这是整个傅里叶体系能成立的基石：因为基两两正交，分解才**唯一**——每个分量只贡献自己的系数，不干扰别人。（demo 拆解模式下把 k 从成分频率挪开一格，能看到乘积面积正负恰好抵消为零，就是这条式子的直观样子。）

## 原理二：求系数 = 投影

怎么知道信号里每个正弦分量有多大？和三维空间求坐标完全同构——**做内积（投影）**：

```text
a(k) = (2/N) · Σₙ x(n) · sin(2πkn/N)
```

拿基波当「探针」与信号逐点相乘再求和：同频成分同号积累出大值，其余成分因正交性正负抵消，只留下 k 自己的分量。向量点积分出 xyz 坐标，信号内积分出各频率系数——**同一件事，只是基从三根轴变成了无穷多根**。

把系数 a(k) 按频率排开画出来，就是常说的「频谱」；所谓变换，就是这串系数的求解过程。

## 原理三：合成 = 加权和，收敛由光滑度决定

反过来，把基按系数加权求和就还原信号（傅里叶级数）。逼近的快慢取决于信号的**光滑度**：

| 信号 | 系数衰减 | 需要的项数 |
| --- | --- | --- |
| 三角波（连续，只有折角） | ~1/n² | 几项就很像 |
| 锯齿波（有跳变） | ~1/n | 需要几十项 |
| 方波（对称跳变） | ~1/n（仅奇次） | 需要几十项 |

**边沿越尖，高次基的系数越大**——「突变」本质上是「大量高频正弦的叠加」。（完整形式里正弦基与余弦基成对使用以确定分量的相位，合并写成复指数 e^(−i2πkn/N)；FFT 只是算这串系数的快速算法，不改变原理。）

### 两个必然现象，都是原理的直接推论

- **吉布斯现象**：跳变处的高频系数衰减慢（1/n），截断级数后丢失的尾部在跳变两侧聚成约 8.95% 的固定过冲——N 再大也不消失；
- **泄漏**：截断信号等于乘上矩形窗，窗内的基不再严格正交，系数被「污染」到邻近 k 上，谱线长出裙边。

## 现象速查（原理视角）

| 现象 | 原理出处 |
| --- | --- |
| 方波只含奇次谐波 | 半波对称性使偶次系数为零（基的对称性选择） |
| 脉冲越窄，频谱越平 | 时间上越集中，各基系数越接近均等（δ 极限） |
| 非整数周期落窗 → 裙边 | 截断破坏正交性，系数互相泄漏 |
| 系数能唯一还原信号 | 正交基的分解唯一性（内积投影） |
| FFT 快 | 系数求解的递归分治算法，与原理无关 |

试这些操作：

1. **合成模式**选方波「▶ 逐项搭建」→ 看加权和如何逼近目标；切三角波对比 → 光滑信号 1/n² 快收敛，需要的基少得多；
2. 观察跳变处的过冲读数 → 始终徘徊在 9%（吉布斯：高频尾部被截断的代价）；
3. **拆解模式**（双音信号）：k 对准 5 → 乘积面积大幅积累（投影命中）；把 k 挪到 6 → 正负面积**恰好抵消为零**——正交性的直接证据；
4. 「🔄 扫描全频段」→ 逐根基投影一遍，系数序列（即频谱）逐根点亮；
5. 切「拍频·泄漏」→ 11.5 不是整数周期，窗内正交性被破坏，系数污染到邻近 k——裙边就是正交性失守的样子。
