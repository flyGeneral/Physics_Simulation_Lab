# 日食 · 三维日地月

> 关键词：轨道倾角、交点、本影锥、全食/环食/偏食

## 原理：为什么不是每个月都有日食

日食的必要条件是**朔**（月球在日地之间）。但若白道（月球轨道面）与黄道（地球轨道面）重合，每个月朔日都会发生日食——实际上两者有 **5.15° 夹角**：多数朔日，月球从太阳的上/下方掠过，月影投偏；只有朔恰好落在**交点**（两轨道面的交线方向，金色标记）附近，「三星一线」才成食。这解释了两件事：

1. 日食每年至多 2~3 次、总发生在朔日附近；
2. 日食季节每 6 个月（交点年的一半）循环一次。

### 三类日食由几何距离决定

本影锥长度由**真实月地距离**算出，与地球表面比高低：

| 类型 | 几何条件 | 现象 |
| --- | --- | --- |
| 全食 | 本影锥尖够到地面 | 月面完全遮日，日冕与钻石环可见 |
| 环食 | 锥尖差一点（金环） | 视直径月 < 日，留一圈金环 |
| 偏食 | 只有半影扫过 | 日面缺一角 |

月轨是椭圆：月球在近地点附近时视角径大，更容易全食；远地点附近则偏环食。

> 精度说明：演示采用 J2000 轨道根数 + Meeus 简化式（13 项黄经、8 项黄纬摄动），食表以 3 小时步长扫描朔并二分精化——时刻误差可达数小时，只讲几何原理，不用于观测预报。
