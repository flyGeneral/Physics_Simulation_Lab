# 黑洞模拟

> 关键词：克尔时空、引力透镜、光子环、ISCO、多普勒增亮

## 原理：每个像素都是一次测地线积分

画面不是「贴图造假」：对每个像素从相机**反向发射光线**，在弯曲时空中数值积分（Kerr-Schild 形式 + RK4，动量逐步重整化回零测地线约束），光线走到哪、画面就画到哪。于是所有广义相对论标志效应**自然涌现**，不需要单独画：

- **引力透镜**：背景星光被弯曲——星星拖影、爱因斯坦环自动出现；
- **黑洞阴影与光子环**：临界撞击参数 b ≈ √27/2 · rs 以内的光线被捕获，形成阴影；光子球（r = 1.5 rs）附近绕行多圈的光线堆出细细的光子环；
- **盘的「上下翻折」**：吸积盘后方的光被弯到黑洞上下方——不用俯视也能同时看到盘的背面。

### 自旋改变一切

克尔黑洞的自旋 a/M ∈ [0, 0.998] 连续可调：

| 效应 | a/M = 0（史瓦西） | a/M = 0.9+ |
| --- | --- | --- |
| 最内稳定圆轨道 ISCO | 6M | 收缩至约 1.24M（Bardeen 公式） |
| 黑洞阴影 | 对称圆 | 不对称 **D 形**（参考系拖曳） |
| 盘亮度 | 多普勒不对称较弱 | 一侧明显增亮（拖曳加强不对称） |

### 相对论增亮

盘物质轨道速度 β ≈ √(M/r)：接近我们的一侧因相对论多普勒 + 引力红移（T_obs = T·δ·√(1−2M/r)，I ∝ δ³）**更蓝更亮**，远离侧暗红。吸积盘温度按薄盘廓线 T ∝ r^(-3/4) 分布、黑体色映射，差速旋转把纹理自然剪切成螺旋流苏。

> 数值验证：积分器梯度与有限差分一致（<1e-8）；a=0 临界撞击参数 b=√27·M、a=0.9 光子轨道半径与解析解吻合到四位小数。
