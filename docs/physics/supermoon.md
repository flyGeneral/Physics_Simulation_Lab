# 超级月亮 · 三维地月

> 关键词：椭圆轨道、近点月与朔望月、会合周期、视直径

## 原理：一个双钟追及问题

月球轨道是椭圆（e = 0.0549，倾角 5.145°），地球位于焦点。「超级月亮」= **满月恰逢近地点**——这是两根指针的追及问题：

- **金针**：满月周期（朔望月）29.53 天，月—地—日成一线；
- **银针**：近地点周期（近点月）27.55 天，月球回到轨道最近点。

金针每圈落后约 2 天，重合周期（会合周期）约 **413 天**——所以「超级月亮」一年多一遇，不是稀有天象。

距离决定观感：视直径 = 31.1′ × (385000 km ÷ 当前距离)，近地点满月比远地点满月**大 14%**；亮度按距离平方反比，**亮约 30%**。

### 科普要点

- 裸眼几乎辨不出 14% 的尺寸差；震撼照片多靠地平线低月与「月亮错觉」加成；
- 「超级月亮」一词 1979 年由占星师 Richard Nolle 所造，天文学的称呼是「近地点满月」；
- 近地点满月时潮汐约 +10–15%，影响有限。

## 现象速查

| 说法 / 现象 | 解释 |
| --- | --- |
| 超级月亮很稀有？ | 会合周期约 413 天，一年多一遇 |
| 肉眼明显变大变亮？ | +14% / +30%，无参照时裸眼难辨 |
| 会引发灾难？ | 潮汐增幅 10–15%，正常天文潮范围内 |
| 为什么照片特别震撼？ | 地平线低月 + 月亮错觉 + 摄影透视 |
