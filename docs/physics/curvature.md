# 曲率驱动 · 空间的冲浪

> 关键词：阿库别瑞度规、曲速泡、负能量、光速场、科幻 vs 物理

## 两种「曲率驱动」，一个根本分歧

**真实物理 · 曲速泡（Alcubierre 1994）**：前方空间收缩、后方膨胀，泡内的船被时空**整体搬运**——局域光速恒为 c₀，但坐标速度可以超光速。熄火后时空完全复原，一粒痕迹不留。数学上与广义相对论相容；代价是泡壁需要**负能量（奇异物质）**，且受量子不等式、视界控制与因果律制约——超光速版本至今无实现路径，2021 年后的正能量改型只能亚光速。

**《三体》· 光速涂改（小说设定）**：曲率引擎把身后空间的光速**永久调低**，飞船被前后光速差推着滑行；尾迹永不消散、缓慢扩散，是「黑域」的雏形。「永久涂改局域光速」目前无任何理论支持。

一句话对比：**小说改写光速，现实只临时弯曲几何。**

## 各看什么

| | 曲速泡（真实物理） | 光速涂改（《三体》） |
| --- | --- | --- |
| 网格 | 泡前加密（收缩）、泡后疏散（膨胀），泡内随船流动 | 尾迹处下沉变暗、缓慢扩散 |
| 光脉冲 | 被泡携带；超光速时在前壁堆积、蓝移成亮带 | 进尾迹就减速变红、追不上船 |
| 痕迹 | 熄火即完全复原 | 航迹永续，误入的船会被拖慢 |
| 数据卡 | 泡速度（坐标）、局域光速（恒 c₀）、负能量需求 | 船速、尾迹最低光速、航迹覆盖率 |

超光速泡的**前壁视界**值得细看：被追上的光子堆积蓝移——舱内无法向前发信号，也就无法转向刹车，这是超光速曲率的根本性困难之一。
