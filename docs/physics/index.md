# 物理演示

本栏目沉淀**通用物理知识**的演示与讲解——不绑定具体器件，按五大类别编排：

## 自然奇观

### 🪐 七星连珠 · 行星巡游

J2000 星历驱动的交互太阳系：俯视 2D / 三维 3D 双模式、地球黄昏视域扇区、四十年连珠日历——回答「连珠」是什么、有多稀有、有没有危害。

- [专题文档：七星连珠](/physics/planets)

### 🌕 超级月亮 · 三维地月

双周期追及问题：朔望月 29.53 天追近点月 27.55 天，约 413 天一次「近地点满月」——大 14%、亮 30% 的真相与错觉。

- [专题文档：超级月亮](/physics/supermoon)

### 🌑 日食 · 三维日地月

为什么不是每个月都有日食？答案在白道与黄道 5.15° 的夹角与交点里；本影锥长度由真实月距算出，全食/环食/偏食三类几何一目了然。

- [专题文档：日食](/physics/eclipse)

### 🌌 极光 · 天空的窗帘

太阳风、磁场与高层大气原子的合奏：颜色即高度表（氧绿/氧红/氮紫蓝），Kp 指数驱动极光带升降，CME 磁暴让低纬也能见极光。

- [专题文档：极光](/physics/aurora)
