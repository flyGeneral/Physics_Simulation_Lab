# 物理演示

本栏目沉淀**通用物理知识**的演示与讲解——不绑定具体器件，天文、光学、力学、波动……任何适合「看动画学原理」的主题都放这里。

## 现状

栏目已就位，首批专题制作中。计划中的方向：

- **波动与光学**：双缝干涉、彩虹与日晕的光路、泊松亮斑
- **运动与混沌**：双摆、三体、共振与拍频
- **场与引力**：引力透镜、时空弯曲
- **工程物理**：流场、结构共振
