# 都江堰分水模型

> 关键词：弯道环流、分水分沙、溢流堰、节流限流、无坝引水

## 原理：不用一道闸门的水利智慧

都江堰（公元前 256 年）无坝无闸，靠三道结构接力把「分水、排沙、限流」全部交给水流自身的物理：

### 1. 鱼嘴分水堤 —— 弯道环流与「四六分水、二八分沙」

岷江在此转弯。弯道水流发育**螺旋环流**：表层清水惯性大，冲向凹岸（内江侧）；底层挟沙水被河床摩擦拖住，沿床面走向凸岸（外江侧）。鱼嘴正放在弯道顶点、内江开在凹岸迎流——粗沙跟着底层水走外江，约 **80% 泥沙排出（二八分沙）**。

分水比例由过水断面自动调节：「内江深窄 / 外江宽浅」——枯水水位低，水全走内江深槽（约六成，保灌溉）；洪水水位高，外江宽浅断面增长更快（内江份额降到约四成，保泄洪）。**四六分水，随季节反转，没有一道闸门。**

### 2. 飞沙堰 —— 溢流二次排沙

内江进流超过约 200 m³/s 时从堰顶自动溢回外江；弯道环流继续把底沙推向堰侧，堰头强螺旋涡把底沙掀起抛回外江（「飞沙」之名）。宝瓶口侧向取水角度让洪水主流裹沙直冲过堰、清水转弯进瓶口——进入内江的沙石最多约 70% 由此排出。

### 3. 宝瓶口 —— 限流与「引清排浑」

瓶口（约 20.4 m 宽）断面骤缩，进流量被锁死在阈值内：**无论上游来多大水，灌区进流几乎不变**（「分四六、平潦旱」）。瓶口前回流漩涡把靠近瓶口的底沙卷回堰口，过瓶口的只剩细颗粒悬沙——随灌溉水淤在田里反成肥料。残余淤积靠岁修「深淘滩、低作堰」清除。

## 现象速查

| 现象 | 机理 |
| --- | --- |
| 枯水灌溉有水、洪水灌区不淹 | 四六分水随水位自动反转 + 瓶口限流 |
| 不设滤沙装置却清水进田 | 弯道环流 + 飞沙堰 + 瓶口回流，三道接力排沙 |
| 「深淘滩、低作堰」 | 这套机理的运维手册：河床清淤保深槽、堰顶低保溢流 |

> 数值按都江堰景区原理展板口径校准；流量数值为示意量级，用于展示机理，不是水文实测。

## 交互演示

俯瞰视角粒子仿真：岷江来水 → 鱼嘴 → 内江/外江 → 飞沙堰 → 宝瓶口 → 灌区。

试这些操作：

1. 拉**上游来水**滑杆从枯水（300 m³/s）到洪水（5000 m³/s）→ 观察内江份额从六成滑向四成、飞沙堰开始溢流、宝瓶口进流几乎不变；
2. 开「**浑水着色**」→ 琥珀色底层含沙粒子走外江、清水进内江——水沙分道肉眼可见；
3. 开「**环流剖面**」→ 看鱼嘴上游横断面：表层清水向凹岸、底层浑水向凸岸的螺旋流插图；
4. 读右上数据卡：来水、宝瓶口进流、飞沙堰溢流、外江下泄、泥沙外排比例——与粒子路由同一套概率。
