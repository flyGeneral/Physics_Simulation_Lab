# 极光 · 天空的窗帘

> 关键词：太阳风、磁层、场线沉降、原子发光、Kp 指数

## 原理：太阳风、磁场与高层大气的合奏

极光是三条链条的串联：

1. **太阳风**：太阳持续抛出带电粒子流；剧烈时以 **CME（日冕物质抛射）** 形式成团抵达地球；
2. **磁层偏转与漏斗**：地球偶极磁场在向阳面挡住粒子流（磁层顶），部分粒子沿**磁场线**螺旋沉降进两极附近——所以极光出现在**极光椭圆带**（磁纬约 67° 附近的环），而不是地理极点正上方；
3. **原子发光**：沉降粒子撞击高层大气原子，激发出特征谱线——

| 颜色 | 来源 | 高度 |
| --- | --- | --- |
| 绿色（最常见） | 氧 557.7 nm | 100–250 km |
| 红色顶帘 | 氧 630 nm | 更高层 |
| 紫蓝色下缘 | 氮分子带 | ~100 km |

**颜色即高度表**：帘幕下缘紫蓝、主体绿、顶转红，对应不同高度的优势发光原子。

**Kp 指数**（0–9）刻画地磁活动：Kp 越高，极光椭圆带越亮、越向低纬扩张（赤道侧边界经验式 67° − Kp×2.4）。极端磁暴（如 1859 年卡林顿事件，Kp≈9）时低纬也能见极光。

### 为什么是「窗帘」

磁场线在两极附近近乎竖直，粒子沿场线沉降，发光区域随场线排布成**竖直条纹的帘幕**；多条场线并列加上风场剪切，帘幕便随风摆动、扭出褶皱。

> 说明：演示为着色器艺术化示意（噪声帘幕 + 高度配色），非磁流体力学精确解。

试这些操作：

1. 拉高 **Kp 滑杆** → 帘幕变亮变高，极光带向低纬扩张；
2. 把**观测站磁纬**从 70° 调到 45° → 平时看不到极光；
3. 点「**CME 爆发**」→ 磁暴冲击，Kp 冲到 9，低纬观测站也能「看到」极光（对照卡林顿事件）；
4. 看磁层插图：太阳风从左吹来被磁层顶偏转，粒子沿场线螺旋沉降两极。
