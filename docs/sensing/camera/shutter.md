# 快门类型与曝光时序

> 关键词：全局快门、卷帘快门、果冻效应、闪光带、逐行读出

## 原理：sensor 是「逐行」工作的

像素并不能「一瞬间」集体完成拍照。曝光结束后的读出（把电荷转成数据）必须按行进行——每行的数据要经过共享的列 ADC 与输出总线。于是有两种组织方式：

**全局快门（Global Shutter, GS）**：所有像素**同时**开始、同时结束曝光；曝光结束后把电荷存进每像素的存储结点，再逐行读出。代价：每个像素多一个存储结点 → 开口率（填充因子）下降、满阱变小、成本高，低光与噪声指标通常劣于同代卷帘。

**卷帘快门（Rolling Shutter, RS）**：第 0 行先开始曝光，隔 `t_row`（行周期）后第 1 行开始……最后一行比第一行晚 `t_readout = t_row × 行数` 才开始曝光。**画面不同高度记录的是不同时刻的世界**。收益：像素设计简单、开口率高、分辨率容易做大、便宜。

```text
全局快门                     卷帘快门
时间 →                       时间 →
█████████ 全部行同时曝光      行0 ████████
                             行1   ████████
                             行2     ████████
                             行3       ████████   ← 读出呈阶梯状扫过画面
```

## 现象与物理

### 果冻效应（jello / jellying）

画面中高速运动的物体发生弯曲、倾斜。原因：第 y 行的采样时刻为 `t(y) = t0 + y·t_row`。一把转速 ω 的风扇叶片，在顶行和底行被采样时角度差了 `Δθ = ω·t_readout`，于是笔直的叶片被「剪切」成弯曲。畸变量与**转速 × 读出时间**成正比，与曝光时间无关——这是它区别于运动模糊的关键。

### 闪光带（partial exposure / flash banding）

短促强光（闪光灯、LED 频闪）只持续一部分行周期的若干毫秒。卷帘快门下，只有曝光窗口与闪光重叠的行被照亮 → **画面一半亮一半暗**，交界处一条硬边。全局快门则整帧均匀受光。

### 频闪条纹（flicker banding）

50 Hz 市电的荧光灯/劣质 LED 光强以 100 Hz 波动。卷帘逐行扫描时，不同行落在光波动的不同相位上 → 画面出现周期性明暗横纹。对抗方法：曝光时间取光波动周期的整数倍（100 Hz 下即 10 ms 的整数倍）。

## 测试方法

| 测试 | 器材 | 步骤 | 判据 |
| --- | --- | --- | --- |
| 果冻畸变 | 电风扇 / 贴条纹的电机转盘，固定机位 | 逐步提高转速拍摄，对比画面顶部与底部叶片角度 | 叶片出现可测弯曲即卷帘；估算 `t_readout = Δθ/ω`，与规格书核对 |
| 闪光带 | 手机手电筒频闪 App / 相机闪光灯 | 暗环境中随机触发短闪光连拍 | 出现半幅亮暗 = 卷帘；整帧均匀 = 全局 |
| 频闪条纹 | 50 Hz 荧光灯 / 可调频闪 LED | 不同曝光时间拍摄均匀白墙 | 有横纹 → 光源频率与行扫描拍频；曝光取 10 ms 整数倍后条纹消失 |
| 读出时间定量 | LED 点阵时钟 / 示波器点光源 | 拍摄已知时刻点亮的光源阵列，看哪些行捕到光 | 由亮暗分界行号反推 t_readout |

试这些操作：

4. 调小读出时间 → 卷帘畸变减轻（这就是高帧率/快速读出卷帘的卖点）。

## 选型建议

- 场景有**高速运动 + 精确几何测量**（机器视觉、无人机、运动相机、VR 定位）→ 全局快门优先；
- 场景静止或低速（安防定点、会议、扫码）→ 卷帘性价比更高；
- 卷帘不可避免时，选**读出时间短**（高 MIPI 速率、少行数、Fast Readout 模式）的方案，或把闪光/频闪源的相位与读出对齐；
- 多目同步系统注意：卷帘的「帧起点」只是第 0 行的时刻，跨 sensor 对齐要按行时刻算。
