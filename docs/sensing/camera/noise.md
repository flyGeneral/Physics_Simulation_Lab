# 噪声、曝光与动态范围

> 关键词：光电转换、散粒噪声、读出噪声、SNR、满阱、动态范围

## 原理：光子 → 电子 → 数值

sensor 的每个像素是一个「光子计数器」：

1. **光电转换**：光子打进硅，以量子效率 QE 的概率激发一个电子，收集到势阱里。曝光时间 `t` 内平均收集 `N = Φ·QE·t` 个电子（Φ 为到达光子通量）。这一步是**离散计数过程**；
2. **读出**：曝光结束后电荷被转换、放大、量化为数字值（DN）。

### 三层噪声，物理来源各不相同

| 噪声 | 物理来源 | 统计模型 | 大小 |
| --- | --- | --- | --- |
| 散粒噪声（shot noise） | 光子到达是随机离散事件 | 泊松分布 | σ_shot = √N（电子数） |
| 读出噪声（read noise） | 电荷转移、放大器、ADC 热噪声 | 近似高斯 | σ_read（典型 1~10 e⁻） |
| 暗电流散粒噪声 | 热激发电子混入势阱 | 泊松 | √(I_dark·t)，随温度每 6~8 °C 翻倍 |

关键直觉：**信号 N 增大时，散粒噪声只按 √N 增长**，所以

```text
SNR = N / √(N + σ_read²)      （电子域）
```

- 强光（N 大）：SNR ≈ √N —— 只受散粒噪声限制，**唯一改善办法是收更多光子**（更长曝光/更大像素/更高 QE）；
- 弱光（N 小）：SNR ≈ N/σ_read —— 读出噪声主导。

### 增益救不了 SNR

模拟增益把「信号 + 噪声」一起放大，SNR 分毫不变；数字增益更是在量化之后再放大，连量化噪声一起放大。增益的作用是**把信号抬到可用的亮度范围**，不是去噪。低光画质的唯一出路是更多光子。

### 动态范围（DR）

```text
DR = 20·log10( N_fullwell / σ_total_dark )   dB
```

即「最亮可测信号」与「暗场总噪声」之比。大满阱（大像素）与低读出噪声共同决定 DR；HDR 模式（长短曝合成）是在读出链路上「作弊」扩展 DR，代价是运动伪影与时序复杂度。

## 测试方法

| 测试 | 器材 | 步骤 | 判据/输出 |
| --- | --- | --- | --- |
| 时域噪声（平场法） | 均匀面光源（积分球最佳） | 固定增益/曝光，连拍 ≥50 帧；逐像素求时间标准差 | 各亮度下的 σ(NDN)，拟合出读出噪声与转换增益 |
| 暗场噪声 | 遮光盖 | 同增益连拍 ≥50 帧 | 暗场 σ 与均值 → 读出噪声、暗电流 |
| PRNU（不均匀性） | 均匀面光 | 单帧除以均值 | 固定模式噪声占比 |
| SNR-亮度曲线 | 可调光面源 | 扫不同曝光/亮度，记录均值与σ | 画 SNR vs 信号量曲线，与 √N 理论线对比 |
| 暗电流-温度 | 温箱 | 不同温度拍暗场 | σ 随温度指数增长，外推长曝/高热场景 |

参考标准：EMVA 1288 定义了完整的表征流程（QE、转换增益、DSNU/PRNU、暗电流、DR、SNR 曲线）。

## 参数仿真台

调节**亮度、曝光时间、增益、读出噪声**，观察灰阶标板的成像：散粒噪声如何随亮度变化（√N 规律）、增益为何救不了 SNR、读出噪声在暗部如何浮现。

试这些操作：

1. 亮度拉到最低 → 看灰阶低段被噪声淹没，注意读数里的 SNR；
2. 保持低亮度，拉高增益 → 画面变亮但噪声颗粒同步变粗，SNR 读数几乎不动；
3. 拉长曝光时间 → SNR 以 √N 速度改善，暗部细节逐渐浮现；
4. 读数面板实时显示各灰阶的电子数、σ、SNR 与动态范围，可与 √N 理论对照。

## 选型速查

- 看低光：优先看 **像素尺寸 × QE × 读出噪声**（e⁻），而不是「最低照度 lux」（口径经常缺省）；
- 看画质上限：满阱容量决定 DR 上限与高光滚降；
- BSI（背照式）工艺提高开口率与 QE，同尺寸像素低光更好；
- 对比两颗 sensor：同一曝光下比「电子数-噪声」曲线，别比 DN 值（增益标定不同没有可比性）。
