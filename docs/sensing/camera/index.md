# Camera Sensor 选型测试地图

拿到一颗 camera sensor（或一颗模组），选型阶段**可以测什么**？本页是一张总地图：每个测试项给出「测什么 / 背后的物理 / 常见坑」，并链接到详细专题页（原理 + 测试方法 + 交互演示）。

## 选型权衡速查

参数之间几乎没有「免费午餐」，选型的本质是确认**你的场景愿意牺牲什么**：

- **全局快门 vs 卷帘快门**：全局快门每像素多一套存储结点 → 开口率下降、低光性能变差、成本高；卷帘便宜、分辨率容易做高，但高速运动畸变与闪光带无法根除。 → [快门专题](/sensing/camera/shutter)
- **大像素 vs 高分辨率**：同靶面下像素越大满阱越大、散粒噪声相对越小（SNR ∝ √N），低光越好；分辨率则相反。
- **帧率 vs 带宽/功耗**：帧率翻倍，MIPI 带宽、功耗、读出压力都近似翻倍；曝光时间上限也被帧周期压短。
- **增益 vs 曝光时间**：低光下「拉增益」和「拉曝光」都能提亮，但只有曝光时间真正收集更多光子、改善 SNR；增益只是放大信号与噪声。 → [噪声专题](/sensing/camera/noise)
- **数字增益 vs 模拟增益**：模拟增益在量化前放大，能压制 ADC 量化噪声；数字增益在量化后放大，连量化噪声一起放大。优先用曝光，其次模拟增益，最后才是数字增益。

## 测试前置条件

做任何一项测试前，先固定变量：

1. **锁参数**：关掉一切 ISP 自动策略（AE/AWB/降噪/sharpen），用 raw 或锁定增益曝光输出，否则测的是 ISP 不是 sensor；
2. **控环境**：光源频谱与频闪（直流 LED 或日光）、环境温度、暗场（遮光盖）与平场（均匀面光源）条件；
3. **留记录**：每一帧记录增益、曝光时间、温度，测试数据与现象一一对应，可复盘。

通用方法（对比实验、故障复现、数据导出）见 [测试方法论](/sensing/methodology)。
