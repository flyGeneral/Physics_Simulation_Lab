# 帧率与运动采样

> 关键词：时间采样、Nyquist、运动模糊、漏检、车轮错觉

## 原理：相机是对时间维度采样

视频 = 每隔 `T = 1/fps` 秒对世界采样一次。采样定理同样适用于时间轴：**变化频率超过 `fps/2` 的运动，采样后无法忠实还原**——它们会「混叠」成更低频的假象。

### 两种不同的「看不清」

| 现象 | 原因 | 与谁有关 |
| --- | --- | --- |
| 运动模糊（motion blur） | 单次曝光时间内物体持续移动，能量在像素上积分 | 曝光时间 t_exp |
| 漏检 / 时间混叠（temporal aliasing） | 帧间发生的事没被采样到，或高频运动折算成低频假象 | 帧率 fps |

两者独立：高帧率 + 长曝光 = 每帧都糊但不漏事件；低帧率 + 短曝光 = 每帧清晰但事件在帧间凭空消失。

### 车轮错觉（wagon-wheel effect）

轮子转速 ω，帧率 f_s。采样后看到的角速度是 ω 折算到 `(-f_s/2, f_s/2]` 内的等效值：

```text
ω_视 = ω - round(ω / f_s) · f_s
```

于是正转的轮辐在视频里可能静止、倒转——这正是麦克风采样混叠（[Mic 篇](/sensing/mic/aliasing)）的旋转版，数学同源：都是 Nyquist 采样定理。

### 漏检窗口

短于帧间隔 `T` 且落在两帧之间的事件，采样后完全不可见。高帧率压缩漏检窗口，但受制于读出带宽与最低曝光时间；爆闪 LED、昆虫振翅、滴落液滴都是典型漏检源。

## 测试方法

| 测试 | 器材 | 步骤 | 判据 |
| --- | --- | --- | --- |
| 有效帧率 | 手机秒表/LED 时钟 App | 连拍读时间戳，统计帧间隔分布 | 平均间隔 = 标称值？抖动（jitter）多大？掉帧率多少 |
| 运动模糊 | 转盘贴条码/刻线，可调转速 | 固定曝光拍不同线速度，量拖尾长度 | 拖尾像素 = 速度 × t_exp / 像素尺度，反推实际曝光时间 |
| 漏检 | LED 频闪（可调脉宽 ms 级） | 脉宽从 0.1 ms 扫到帧间隔 | 恰好开始「看不见」的脉宽 ≈ 有效漏检窗口 |
| 车轮错觉 | 贴辐条的电机轮 | 转速从慢到快扫 | 视觉转速与真实转速不符/倒转的区间 |

## 参数仿真台

轮辐以连续角速度旋转，相机按可调帧率采样。左看真实运动，右看「相机看到的」采样保持结果，读数实时显示真实转速与视觉转速。

试这些操作：

1. 「轮子」模式下把转速从慢拉快 → 辐条先同向慢转，超过 Nyquist 后**倒转**，在整数倍帧率处完全静止；
2. 观察读数 `ω_视 = ω − round(ω/f_s)·f_s` 与画面是否一致；
3. 切到「声波」模式 → 同样的数学换了个皮肤：正弦声波被低采样率重建成「低频假音」；
4. 打开「抗混叠滤波」→ 高于 Nyquist 的成分在采样前被抑制，假象消失（信号也随之损失）——这就是 mic 内置抗混叠滤波的意义。

## 选型速查

- 关注**帧率 × 最低曝光时间**两者：帧率决定漏检窗口，最低曝光决定单帧模糊下限；
- 高速检测场景按「目标事件时长 ≤ 帧间隔的 1/2」估帧率需求（工程上更保守）；
- 多摄/多传感器系统额外关注**时间戳对齐**：时间偏差等效于运动偏差；
- 车轮错觉不仅是画质问题：基于视觉的转速/振动测量会直接量出错误频率。
