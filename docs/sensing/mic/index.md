# Mic 选型测试地图

拿到一颗麦克风（MEMS 或 ECM）或一个 mic 模组，选型阶段**可以测什么**？与 [Camera 篇](/sensing/camera/) 同构：测什么 / 背后的物理 / 常见坑。

## 器件速览

| 类型 | 原理 | 特点 |
| --- | --- | --- |
| ECM（驻极体） | 振膜电容变化 → JFET 放大 | 便宜、尺寸大、一致性差 |
| MEMS（模拟输出） | 硅微机械振膜 + 内置放大 | 小、一致性好、需外置 ADC |
| MEMS（数字输出 PDM/I2S） | 内置 ΣΔ ADC，输出比特流/音频帧 | 抗干扰好、走线简单、时钟即生命线 |
| 压电 / 骨传导 | 压电片直接感应振动 | 抗空气噪声、频响窄 |

## 测试项总表

| 测试项 | 测什么 | 背后的物理 | 常见坑 | 详细 |
| --- | --- | --- | --- | --- |
| 灵敏度与频响 | 各频率输出幅度、带宽、起伏 | 振膜共振、声孔声学 | 灵敏度 dBFS@94dB SPL 口径要与自校准条件对齐 | 规划中 |
| 本底噪声 / SNR | 等效输入噪声（dBA） | 热噪声、1/f 噪声 | 增益放大「听感变响」不改善 SNR | 规划中 |
| 最大声压级与失真 | THD 起拐点、削波 | 振膜行程饱和、ASIC 削波 | 只看 datasheet 最大 SPL，不看失真条件 | 规划中 |
| 指向性 | omni / 心形 / 8 字极坐标图 | 声程差干涉、双振膜压差 | MEMS 单体多为 omni，指向性靠阵列实现 | 规划中 |
| 采样率与混叠 | 高频成分折返为低频噪声 | Nyquist 采样定理 | 高频嘶声「变成」啸叫，被误判为硬件故障 | [采样率与混叠](/sensing/mic/aliasing) |
| 数字接口与时钟 | PDM/I2S 时钟质量、通道相位 | ΣΔ 调制、时钟抖动 | 时钟抖动直接劣化 SNR；多 mic 相位差决定波束 | 规划中 |
| 电源抑制 | 电源纹波串扰 | ASIC PSRR | 与 codec 同板时嗡声/射频噪声 | 规划中 |

## 选型权衡速查

- **数字 vs 模拟 mic**：数字 mic（PDM/I2S）走线抗干扰、省外置 ADC，但要占用时钟资源且布线时序讲究；模拟 mic 灵活便宜，长走线易受干扰；
- **灵敏度 vs 最大 SPL**：高灵敏度拾取远场细节，但近场大声压更早失真——对讲/音箱近讲场景别盲目追高灵敏度；
- **单体指向性 vs 阵列**：要指向性就得为阵列的**间距与相位一致性**买单（间距 ~ λ/2 与目标频率相关）；
- **采样率余量**：理论上采到目标带宽 2 倍即可，工程上给抗混叠滤波器留过渡带（见 [采样率与混叠](/sensing/mic/aliasing)）。

## 测试前置条件

1. **声学环境**：安静房间或消声箱，底噪至少比被测噪声低 10 dB；
2. **声源标定**：声级计校准声源（94 dB SPL @ 1 kHz 为常用参考点）；
3. **记录链路**：增益、采样率、滤波配置逐项记录；数字 mic 注意主机时钟配置。

通用方法见 [测试方法论](/sensing/methodology)。
