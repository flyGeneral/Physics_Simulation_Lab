# 采样率与混叠

> 关键词：Nyquist、混叠、抗混叠滤波、PDM/I2S、车轮错觉

## 原理

声音是连续的压力波，麦克风链路必须先把它**采样**成离散样本。Nyquist–Shannon 采样定理：

> 采样率 f_s 只能忠实保留 f < f_s/2 的频率成分。高于 f_s/2 的成分不会消失——它们会**折返**到 `[0, f_s/2)` 内，伪装成低频信号。

混叠频率：

```text
f_alias = | f − round(f / f_s) · f_s |
```

听起来是什么：高频嘶嘶声变成奇怪的啸叫/低频毛刺，且**事后无法滤除**——混叠一旦发生，假信号和真信号在数字域不可区分。这与相机帧率不足导致车轮倒转（[帧率与运动采样](/sensing/camera/temporal-sampling)）是同一个数学。

```text
f=3 kHz, f_s=8 kHz  →  正常（3k < 4k）
f=5 kHz, f_s=8 kHz  →  混叠成 3 kHz 假信号
f=8 kHz, f_s=8 kHz  →  折返到 0 Hz（直流漂移）
```

## 抗混叠滤波（anti-aliasing filter）

正确做法在**采样前**（模拟域）用低通滤波器把 f > f_s/2 的成分压掉：

- 模拟 mic：ADC 前必须有模拟 LPF（或依赖 ΣΔ 过采样架构的抽取滤波器）；
- 数字 mic（PDM）：ΣΔ 调制器以几 MHz 过采样，片内数字抽取滤波器完成抗混叠——**滤波器已经是器件的一部分**，这也是数字 mic 好用的原因之一；
- 代价：滤波器不是砖墙，过渡带要占带宽。所以「采 16 kHz 出 7 kHz 带宽」而不同「刚好 2 倍」——给过渡带留余量。

## 测试方法

| 测试 | 器材 | 步骤 | 判据 |
| --- | --- | --- | --- |
| 扫频混叠 | 可发 18~24 kHz 扫频的音箱 + 录音（固定低采样率） | 频率从 1 kHz 扫到超过 f_s/2，看频谱 | 超过 f_s/2 后谱线不升反降 = 混叠折返；折返频率符合公式 |
| 抗混叠衰减 | 同上，开启/关闭链路滤波（若可控） | 对比超过 Nyquist 后的谱幅度 | 优质链路应把折返分量压到本底附近 |
| 听感对照 | 手机外放高频音 | 低采样率录音回放 | 高频源录出低频「怪音」 |

注意安全：长时大音量高频对听力与喇叭都不友好，用小音量、短时长。

试这些操作：

1. 「声波」模式：信号频率 3 kHz、采样率 8 kHz → 采样点完整勾出波形；
2. 信号频率拉过 4 kHz（Nyquist）→ 采样点连成的「重建波形」变成低频假波，读数给出 f_alias；
3. 打开「抗混叠滤波」→ 高于 Nyquist 的成分先被衰减再采样，假波消失；
4. 切「轮子」模式对照：同一公式 `ω−round(ω/f_s)·f_s` 描述车轮倒转。

## 选型速查

- 数字 mic：看 datasheet 的**输出带宽 vs 采样率档位**与片内滤波器衰减曲线，而不是只看最高采样率；
- 模拟 mic + 外置 ADC：确认 ADC 前端有无抗混叠 LPF 及其截止特性；
- 多 mic 阵列：所有通道**同一时钟、同一相位**；采样时钟抖动直接抬升本底噪声；
- 别用「提高采样率」抢救已混叠的录音——那不是分辨率问题，是信息已丢。
