# 音腔与高频跌落

> 关键词：音腔、高频跌落、Helmholtz、声学传输线

## 原理

mic 的频响不只在芯片里——**「声孔 → 音腔 → MEMS 膜片」整条声学路径是一条传输系统**，它有自己的传递函数 H(f)。datasheet 给的是自由场/测试腔条件下的曲线；装进整机结构后，高频段往往由音腔说了算。规则音腔（等截面直管）近似一段均匀传输线，在音频段内近似平直；**异形音腔里的每处截面突变、台阶、弯折、突然扩张，都是一个阻抗失配点**，级联起来等效为一串 LC 低通滤波节——高频被反射回孔外或耗散在局部，膜片处看到的就是高频跌落。

### 机理一：Helmholtz 结构本质是低通

最简集总模型：声孔 = 声质量 `M_a = ρ₀·l/S`，腔体容积 = 声顺 `C_a = V/ρ₀c²`，谐振频率：

```text
f₀ = 1 / (2π·√(M_a·C_a)) ≈ (c/2π)·√( S / (l·V) )
```

低于 f₀ 近似平直，**高于 f₀ 以约 −12 dB/oct 滚降**（孔内空气惯性把膜片与外界解耦）。规则小音腔能把 f₀ 推到 20 kHz 以外；异形腔有效容积偏大、又常有收窄段，两个因素都把 f₀ 压进可听频段——跌落点从超声区挪进 4–8 kHz 一眼可见的位置。

### 机理二：截面突变反射与级联频选衰减（主因）

波从面积 A₁ 的段进入 A₂ 的段，压力反射系数：

```text
r = (A₁ − A₂) / (A₁ + A₂)
```

单个突变处的平面波反射近似**与频率无关**——它带来两个后果：一是平坦的电平偏移（阻抗变换，p ∝ 1/√S，扩张 6 倍 ≈ −7.8 dB），二是反射波与入射波干涉出**强烈频率选择**的驻波场。真正的宽带高频跌落来自**级联**：多处突变的间距与波长可比时（10 kHz 时 λ ≈ 3.4 cm，5 kHz ≈ 6.9 cm——正是音腔里台阶的尺度），各结点的反射同相叠加形成宽阻带，等效一串 LC 低通滤波节；真实异形音腔是大量随机分布的突变，阻带被抹成平滑的高频下探。此外弯折与腔内厘米级特征会把平面波能量散射进高阶消逝模、就地耗散——只砍高频的机制。

### 机理三：驻波凹陷宏观读作「高频跌落」

腔长 L 支撑 λ/2 驻波，`f_dip ≈ n·c/2L`：3 cm 路径第一个凹陷就在 5.7 kHz 附近。若膜片入口恰好落在某模态的声压节点，出现深 notch。异形腔模态复杂、节点不可控，频响曲线上表现为高频一堆 dip，扫频平均后看上去就是整体往下掉。另有粘热边界层损耗随频率上升（1 kHz 时边界层 ≈ 69 µm，10 kHz ≈ 22 µm），窄缝窄口对高频额外加阻尼。

### 为什么「规则 + 密封好」的音腔没有这个问题

把「普通、密封性好的音腔」拆成两条性质看：

- **规则（等截面、短、小容积）**：整条路径处处 r = 0，没有级联反射节点——带内是一根「透明」传输线；短孔 + 小前腔把 Helmholtz 谐振 f₀ 推到 20 kHz 之外，−12 dB/oct 滚降不出现在带内。膜片拿到的能量不会被中途弹回孔外；
- **密封好**：声路径**唯一且与设计一致**。泄漏等效于给音腔并联一条旁路声质量：①旁路与主路径的延迟差造成双径干涉（梳状起伏）；②低频被低阻旁路「短路」，灵敏度低频塌陷；③腔内驻波图样偏离设计。密封好 = 不往声学网络里塞设计之外的元件。

一句话：**异形的问题是几何级联反射（宽带高频跌落），泄漏的问题是旁路干涉（梳状 + 低频塌陷）**——两种故障签名不同，测试时先看曲线形状再归因。

## 现象与物理

| 现象（回采/录制曲线上看） | 成因 | 方向 |
| --- | --- | --- |
| 光滑高频滚降，f₀ 后 ~−12 dB/oct | Helmholtz 低通（孔质量 + 腔容积） | 减容积、缩短孔 |
| 4 kHz 起宽带下探，突变越多越糟 | 多级突变级联的宽阻带 + 驻波干涉 | 截面恒定、渐变过渡 |
| 梳状 dips，间距 ≈ c/2L | 腔内 λ/2 驻波 | 缩短路径、加阻尼网布 |
| 单个深 notch | 膜片入口落在驻波节点 | 改腔长错开节点 |
| 高频整体「毛糙」跌落 | 高阶模散射 + 粘热损耗 | 去窄口、内壁平滑 |
| 低频塌陷 + 梳状起伏 | 密封泄漏旁路与主路径双径干涉 | 密封工艺（泡棉压缩率 / 点胶连续性） |

## 测试方法

| 测试 | 器材 | 步骤 | 判据 |
| --- | --- | --- | --- |
| 归一化音腔频响 | 音箱扫频 + 参考传声器（贴近声孔）+ 设备 mic 同步录音 | 播 20 Hz–20 kHz 扫频；H(f) = 设备 mic 频谱 / 参考 mic 频谱 | H(f) 解耦掉扬声器自身响应；高频跌落即可归因音腔 |
| 陡降 vs 梳状判别 | 同上 | 看 H(f) 形状 | 光滑滚降 → Helmholtz/低通结构问题；梳状 dip → 驻波问题（间距应 ≈ c/2L） |
| 结构对照 | 同一 mic 模组，直管工装 vs 整机音腔 | 分别测归一化频响 | 差值 = 纯结构代价，用于验收结构与 ID 设计 |
| 自由场 vs 整机 | 消声箱自由场测 mic 模组，再装机测 | 对比两条曲线 | 装机后高频跌落 = 音腔贡献，勿用 datasheet 曲线推整机表现 |

## 结构设计与选型速查

- **走线短而直**：路径长度直接决定第一个驻波凹陷位置（c/2L）；能 2 cm 不要 5 cm；
- **截面恒定，过渡渐变**：锥度/圆角代替台阶——渐变段的反射按面积变化率累积而不是突变跳变（demo 里「渐变锥管」就是证明）；
- **控制前腔容积**：容积越大 f₀ 越低；膜片前的小死区容积尤其要压；
- **阻尼网布**：拿谐振峰值换平坦度，代价是灵敏度——放在孔口或腔内突变处；
- **验收口径**：整机频响 ≠ datasheet 频响；结构评审时把「归一化音腔频响」列为交付项，见[测试方法论](/sensing/methodology)；
- **ID 与声学的冲突**：异形音腔多半是工业设计逼出来的；拿本页仿真台给结构同事演示「突变程度」滑杆，比口头争论有效。
