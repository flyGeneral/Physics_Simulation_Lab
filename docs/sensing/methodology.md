# 测试方法论

器件各测试项的具体做法在各专题页（如 [Camera](/sensing/camera/)、[Mic](/sensing/mic/)），本页沉淀**通用方法**：怎么设计观测、怎么对比、怎么复现故障、怎么沉淀数据。

## 1. 观测方案：先想清楚「看什么」

- **一次只动一个变量**：增益、曝光、温度、供电……多变量同时动，现象无法归因；
- **重复次数给足**：噪声类指标本质是统计量，单帧无意义，≥30 帧起步；
- **对照组内置**：同一场景下保留一台「已知表现」的参考设备，环境漂移时能靠它发现；
- **记录到帧**：每个样本记录完整参数（增益/曝光/采样率/温度/供电/固件版本），事后可复盘。

## 2. 对比实验（A/B）

选型阶段最常见的需求是「A、B 两颗器件谁更适合」：

1. **同一物理场景**：同一光源/声源、同一距离与角度、同一时刻（环境会漂移，轮流交替拍摄优于先拍完 A 再拍 B）；
2. **对齐参数口径**：比较电子域（camera）或同一 SPL/增益（mic）下的表现，不要比较「看起来亮度/响度一样」的输出；
3. **量化指标 + 现象双记录**：SNR 曲线、畸变量、频谱，连同原始帧/录音一起归档；
4. **结论写清条件**：脱离条件的「A 比 B 好」没有价值。

## 3. 故障复现

- **最小化复现条件**：砍掉一切无关环节，把复现所需的最小参数组合找出来（例如「仅当增益≥x 且帧率=y 时出现条纹」）；
- **边界扫描**：在复现条件的上下边界各扫一组，确认这不是概率性偶发；
- **物理归因**：从现象反推物理通路——条纹→频闪/读出；啸叫→混叠/回声；漂移→温度。参考各专题「现象与物理」小节；
- **记录复现率**：N 次中复现 M 次，写进问题单。

## 4. 数据导出与现象复盘

- **时序数据**：帧时间戳、参数日志、传感器读数对齐到同一时间轴；
- **快照与命名**：截图/原始数据命名包含日期+场景+参数，避免三个月后无人认识；
- **时间线重建**：复盘时先画时间线（何时换条件、何时出现现象），再下结论；
- 本站各交互演示的「剧本模式」（如 [卷帘快门时序](/sensing/camera/shutter)）就是时间线重建思维的直接应用。

## 5. 边界与安全

- 本栏目是**原理研究与评估演示**，不做自动化产测工具、不做产线判定；
- 强光源/激光（含 lidar）测试注意人眼安全；声学测试控制音量与时长；
- 器件极限测试（过压、过温）遵循规格书绝对最大值。
