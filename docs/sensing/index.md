# 感知器件评估

本栏目面向 **Camera、Mic、IMU、激光雷达、TOF** 等各类感知器件，回答三个问题：

1. **原理**——器件工作背后是什么物理规律？（光电转换、声学采样、曝光机制、信号噪声……）
2. **选型**——参数表上的每一项意味着什么取舍？（快门类型、曝光时长、采样率、信噪比、视场角、功耗……）
3. **测试**——拿到一颗新器件，可以测什么、怎么测、判据是什么？

> 定位边界：本栏目侧重**原理研究与评估演示**，不是硬件驱动开发，也不是自动化测试工具。

## 如何使用本栏目

每个专题由三部分组成，建议按「**读文档 → 看动画 → 调仿真**」的顺序学习：

- **文档**：原理推导、参数对照表、测试步骤与判据；
- **剧本动画**：确定性时序演示，支持单步 / 暂停 / 回放 / 事件标注，用于看清快速过程；
- **参数仿真台**：自由调节参数，实时观测现象与数值，用于建立 trade-off 直觉。
